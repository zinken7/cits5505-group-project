# Watchlist Hub - Anime/Game/Movie Watchlist

## Project Description

Watchlist Hub is a social watchlist platform for anime, games, and movies, where users can track their viewing/playing progress and discover what others are enjoying. Users create personal watchlists divided into three statuses—"Watching", "Completed", and "Planned"—to organise their media backlog and progress.

## Key Features

- **Personal Watchlists**: Add/remove anime, games, or movies to/from your "Watching", "Completed", or "Planned" lists via smooth AJAX interactions (no page reloads).

- **User Profiles**: View any user's public watchlists, including item counts and status breakdowns to see what they've watched/played.

- **Public Discovery Pages**:
  - "Most-watched anime", "Most-played games", "Most-planned movies"—dynamic leaderboards showing top-counted items across all users.
  - Filterable by status (e.g., "Currently Watching" vs "Completed").

- **Social Discovery**: Explore trending content and follow users' tastes to build your own watchlist.
