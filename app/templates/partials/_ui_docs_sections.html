Semantic colors & surfaces

Prefer these Tailwind tokens (wired in frontend/src/style.css @theme) so layouts respect data-theme (light / dark). Pair bg-* with matching text-* for contrast.

Surfaces & text

bg-page · bg-card · text-foreground · text-muted · border-border

Brand

bg-primary · text-primary · bg-accent · text-accent

primary accent

Semantic status

bg-success · bg-warning · bg-danger

success warning danger

Quick reference

  • Shadow: shadow-elevated on cards/panels.
  • Focus ring: use ring-2 ring-primary/50 or outline-none focus-visible:ring-2 focus-visible:ring-primary/50 on interactive controls.
  • Raw CSS: var(--accent-primary), var(--text-muted), var(--border-default) — see :root / [data-theme="dark"] in the same file.
  • Init: call window.UI.init() after DOM ready; components use data-ui="…".
