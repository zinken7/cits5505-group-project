Accordion

Raw HTML:

<div data-ui="accordion" class="border rounded-lg divide-y">
    <!-- Item 1 (open by default) -->
    <div class="accordion-item is-open">
        <button class="accordion-header w-full flex justify-between items-center p-4 text-left font-medium hover:bg-gray-50">
            What is UI Lite?
            <svg class="accordion-icon w-5 h-5 transition-transform duration-200" ...></svg>
        </button>
        <div class="accordion-content px-4 pb-4 text-gray-600 text-sm">
            A lightweight jQuery component library.
        </div>
    </div>
    <!-- Item 2 -->
    <div class="accordion-item">...</div>
</div>

<!-- Multi-open mode -->
<div data-ui="accordion" data-multiple="true">...</div>

Preview:

Click a header to expand / collapse. By default only one panel opens at a time. Add data-multiple="true" to allow multiple.

UI Lite is a lightweight jQuery-based component library styled entirely with Tailwind CSS utility classes.
Any element with data-ui="accordion" is automatically instantiated on DOMContentLoaded via window.UI.init().

Breadcrumbs

Raw HTML:

<!-- Container only — content is rendered via JS API -->
<nav data-ui="breadcrumbs" id="my-breadcrumbs"></nav>

<script>
// Get the instance and call setItems()
const bc = $('#my-breadcrumbs').data('nuxt-ui-instance');
bc.setItems([
    { label: 'Home', url: '/' },
    { label: 'Settings', url: '/settings' },
    { label: 'Profile' }   // last item = no link (active page)
]);
</script>

Preview:

Use the setItems() JS method to render the breadcrumb trail dynamically. The last item is treated as the active page (no link).

Datepicker

Raw HTML:

<div data-ui="datepicker"
    class="relative w-64 border border-gray-300 rounded-lg px-3 py-2 flex items-center cursor-pointer hover:border-gray-400">
    <svg class="w-5 h-5 text-gray-400 mr-2" fill="none" stroke="currentColor" viewBox="0 0 24 24">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2"
              d="M8 7V3m8 4V3m-9 8h10M5 21h14a2 2 0 002-2V7a2 2 0 00-2-2H5a2 2 0 00-2 2v12a2 2 0 002 2z" />
    </svg>
    <input type="date" class="w-full bg-transparent outline-none text-sm text-gray-700" />
</div>

<script>
const dp = $('[data-ui="datepicker"]').data('nuxt-ui-instance');
dp.getValue();              // returns "YYYY-MM-DD"
dp.setValue('2025-12-31');  // sets the date
dp.setError('Required');    // shows red border
</script>

Preview:

Click anywhere on the wrapper to open the native date picker. The component hides the native calendar icon and provides getValue() / setValue() / setError() API methods.

Toast

Raw HTML:

<!-- No HTML needed! Toast is a Singleton — call from anywhere in JS -->
<script>
// window.UI.toast is auto-instantiated (Singleton)
window.UI.toast.show('Saved!', 'Your changes have been saved.', 'success', 3000);
window.UI.toast.show('Error', 'Something went wrong.', 'error', 5000);
window.UI.toast.show('Heads up', 'New version available.', 'info', 4000);

// Parameters:
// show(title, description, type, duration)
//   type: 'success' | 'error' | 'info'
//   duration: ms (0 = no auto-close)
</script>

Preview:

Toast is a Singleton — no HTML markup needed. Call window.UI.toast.show() from anywhere. Toasts stack in the top-right corner with slide-in animation and auto-dismiss.
