# Watchlist Hub – User Stories by Page

## 1. Landing Page
### User Stories
- As a visitor, I want to see **"Top 10/50 Most Watched Anime"** so that I can discover popular content without logging in.
- As a user, I want to **filter top lists by status** (Watching / Completed / Planned) so that I can see trending active content.
- As a user, I want to **see how many people have an item in their lists** so that I can assess popularity.

---

## 2. Register Page (Create Account)
### User Stories
- As a new user, I want to **create an account with username/email/password** so that I can start tracking my watchlists.

---

## 3. Login Page
### User Stories
- As a returning user, I want to **log in securely** so that I can access my saved lists across sessions.

---

## 4. Logout Page
### User Stories
- As a logged‑in user, I want to **log out** so that I can protect my account on shared devices.

---

## 5. Dashboard Page
### User Stories
- As a logged‑in user, I want a **dashboard showing my 3 lists** (Watching / Planned / Completed) so that I can see my progress at a glance.
- As a user, I want to **add media to my lists** so that I can track my progress.
- As a user, I want to **change an item's status between lists via dropdown** so that I can update my progress instantly.
- As a user, I want to **remove items from my lists** so that I can clean up my tracking.

---

## 6. Profile Page (Other Users’ Profiles)
### User Stories
- As a user, I want to **view another user's profile and their 3 lists** so that I can see what others are watching/playing.

---

## 7. Category Page (Anime/Games/Movies Listing)
### User Stories
- As a user, I want to **view a list of all items in a category** so that I can browse available content.
- As a user, I want to **search for anime/games/movies by title** so that I can quickly find items to add.

---

## 8. Detail Page (Item Detail View)
### User Stories
- As a user, I want to **view detailed information about an item** so that I can decide whether to add it to my watchlist.
- As a user, I want to **see how many people have this item in their lists** so that I can assess popularity.
